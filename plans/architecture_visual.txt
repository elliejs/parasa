 RUNTIME MOUNT TOPOLOGY
═══════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────┐
│  System (mounted at /)                                              │
│                                                                     │
│  /var          <── zbamidbar/system-data/${NAME}/var       (zfs)    │
│  /home         <── zbamidbar/system-data/${NAME}/home      (zfs)    │
│  /tmp          <── zbamidbar/system-data/${NAME}/tmp       (zfs)    │
│  /usr/local    <── zbamidbar/system-data/${NAME}/usr-local (zfs)    │
│                                                                     │
│  All mounts via /etc/fstab (zfs, rw,late). No nullfs.              │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│  Container (jailed at /containers/${NAME})                          │
│                                                                     │
│  /var          <── zbamidbar/container-data/${NAME}/var       (zfs) │
│  /home         <── zbamidbar/container-data/${NAME}/home      (zfs) │
│  /tmp          <── zbamidbar/container-data/${NAME}/tmp       (zfs) │
│  /usr/local    <── zbamidbar/container-data/${NAME}/usr-local (zfs) │
│                                                                     │
│  Cross-mounts (another container/system's data):            (nullfs)│
│  /shared/foo   <── /containers/other/shared/foo                     │
│                                                                     │
│  All mounts via mount.fstab in minhag, processed by jail(8).       │
└─────────────────────────────────────────────────────────────────────┘


═══════════════════════════════════════════════════════════════════════════════
 GIT BRANCH TOPOLOGY (foundation.git)
═══════════════════════════════════════════════════════════════════════════════

Foundation branches are orphans — no shared root.

15-stable-generic	(orphan branch)
	├── ${ARTIFACT-1}	commit msg = artifact name = ZFS snap tag
	├── ${ARTIFACT-2}
	│	├~> containers/webserver
	│	│	├── inaugural
	│	│	├── admin-delta-1
	│	│	└── admin-delta-2	<── current container state
	│	└~> systems/wonderland
	│		├── inaugural	writes /etc/fstab
	│		└── admin-delta-1
	├── ${ARTIFACT-3}
	└── ...

15.1-releng-gaming	(orphan branch)
	├── ${ARTIFACT}
	│	└~> systems/gamebox
	│		├── inaugural
	│		└── admin-delta-1
	└── ...

...	(more foundation orphans)


Rebase (parasa_update):
	git rebase --onto ${NEW-ARTIFACT} ${OLD-ARTIFACT} systems/${NAME}
	The entire delta chain (inaugural + all admin commits) replays onto the new foundation.
